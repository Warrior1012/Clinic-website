# Northstar Clinic Concept

A fictional, responsive clinic website concept built for portfolio demonstration.

**Live demo:** https://northstar-clinic-concept.vercel.app

> This is a fictional portfolio concept. No clinic operates at this address. The enquiry form is a front-end demonstration only; it does not send or store personal information and does not create appointments. Do not enter real medical or personal information.

## Pages
- Home
- Services
- About
- Contact / enquiry preview
- Privacy policy
- Terms
- Refund policy
- Thank-you confirmation
- Error page
- Custom 404 page

## Tech
- Semantic HTML
- CSS with responsive layouts and reduced-motion support
- Vanilla JavaScript
- Static deployment on Vercel

## Run locally
From the repository root, run:

```bash
python -m http.server 8000
```

Then open http://localhost:8000.

## Before any real-world use
Replace all illustrative clinic details and imagery, add verified clinical and legal content, and connect a secure server-side enquiry workflow with appropriate privacy and security controls. The current demo has no database, authentication, notifications, or booking backend.
